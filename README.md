# SOC Analyst Playbook & Detection Lab

This repository is a collection of my notes, detections, and practical blue‑team work as I study and practice SOC analysis. It focuses on the core areas used in real Security Operations Centers: understanding logs, identifying suspicious activity, writing detection rules, and responding to alerts.

## What this repository includes

### Windows Event Analysis
- Common Event IDs (4624, 4625, 4688, 1102, etc.)
- Process execution patterns
- PowerShell abuse and script logging
- LOLBins and how attackers use them

### Linux Log Analysis
- Authentication logs
- Cron job activity and persistence techniques
- Apache access logs and common attack patterns

### Detection Rules
- Process creation detections (Event ID 4688)
- Brute‑force login detection logic
- USB activity alerts
- Data exfiltration thresholds

### SIEM Lab Work
- Notes from hands‑on SIEM exercises (Splunk, Elastic, TryHackMe)
- How alerts were triggered and investigated
- Breakdown of rule logic and matched fields

### Incident Response Notes
- Triage workflow
- Basic malware investigation steps
- Containment and follow‑up actions

## Purpose
I built this repository to organise my learning and to demonstrate practical SOC skills through real examples, detections, and analysis. I will continue updating it as I complete more labs and investigations.
